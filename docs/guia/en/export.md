# Export figures for a paper

1. Open **Tree**.
2. At the top right are **SVG**, **PNG** and **PDF**.

- **SVG** is a drawing that stays sharp when you enlarge it. Use it in an editor.
- **PNG** is an image. Use it on a slide.
- **PDF** is a page. Use it in a report.

Before you export, switch the theme to **Publication** (the button that cycles Light, Dark and Publication). That theme uses a white background and thin lines, which print more cleanly.

The tables on **Results**, the Markov cost-by-period table and other tables have **CSV**. Open it in Excel or LibreOffice.

**Save** (`.healthforest.json`) is not a figure. It is the whole model, so you can keep working later.
