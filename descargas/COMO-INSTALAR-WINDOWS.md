# Cómo instalar HealthForest en Windows

El instalador no tiene firma de pago. Windows te avisa. Es esperable. Sigue estos pasos.

1. Descarga `HealthForest-Windows-Setup.exe` (está en esta misma carpeta).
2. Ábrelo con doble clic.
3. Si aparece la ventana azul **Windows protegió su PC**:
   - Pulsa **Más información**.
   - Pulsa **Ejecutar de todas formas**.
4. Elige el idioma si te lo pregunta (español o inglés).
5. Pulsa **Siguiente** e **Instalar**. No hace falta ser administrador si instalas solo para tu usuario.
6. Abre **HealthForest** desde el menú Inicio.

Si Windows 10 te pide **WebView2**, acepta la descarga. Windows 11 ya lo trae.

## Sin instalar nada

Abre `HealthForest-Portable.html` con Chrome, Edge o Firefox. Es el mismo programa, en un solo archivo. No aparece en el menú Inicio.

También puedes usar el archivo `.msi` (`HealthForest-Windows.msi`) si tu institución instala con ese formato. El aviso de Windows es el mismo: **Más información**, luego **Ejecutar de todas formas**.
